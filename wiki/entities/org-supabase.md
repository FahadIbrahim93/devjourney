# Supabase

> Open-source Firebase alternative. PostgreSQL + Auth + Storage + Edge Functions.

## What They Do
- **Database** — managed PostgreSQL
- **Auth** — OAuth, email, magic link, JWT
- **Storage** — S3-compatible
- **Realtime** — WebSocket subscriptions
- **Edge Functions** — Deno runtime

## Why We Use Them
- SQL is real (vs Firestore's noSQL)
- Row-level security
- Free tier: 500MB DB, 50K auth users
- Open source (self-host if needed)

## Pricing
- **Free:** 500MB DB, 2GB bandwidth
- **Pro:** $25/mo, 8GB DB
- **Team:** $599/mo
