# Obsidian

> Markdown-based knowledge base app. Free for personal use, paid for commercial. The visual frontend for our [[concept-llm-wiki|Second Brain]].

## Features
- **Plain markdown** — files you own, forever
- **Graph view** — visualizes connections
- **Wikilinks** — `[[double bracket]]` linking
- **Backlinks** — auto-tracked
- **Plugins** — Dataview, Templater, Graph Analysis
- **Local-first** — your files, your machine

## Why It's #1
- No vendor lock-in (vs Notion)
- Best graph view
- Mature plugin ecosystem
- Free for personal
- Works on Windows/Mac/Linux/iOS/Android

## Plugins We Use
- **Dataview** — query pages like a database
- **Templater** — templates with variables
- **Calendar** — daily/weekly notes
- **Graph Analysis** — advanced graph features

## Free Alternatives
- **Logseq** — block-based, similar feel
- **SilverBullet** — self-hosted, browser-based
- **VS Code + MD** — just an editor, no graph
