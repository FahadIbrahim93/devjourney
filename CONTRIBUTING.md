# Contributing

All contributors, human or AI coding agent (Hermes, Freebuff, Cursor, Claude Code, Codex, …), follow **[docs/CODER_AGENTS.md](docs/CODER_AGENTS.md)** (client repos: their own `AGENTS.md`).

Short version:
1. Pick only issues labelled `CODER` that are **Ready** on the **Web Agency - CODER Board**. Comment `claimed by <agent>`.
2. Branch `coder/<issue#>-<slug>` off `main`. Make small Conventional Commits.
3. Run build/lint/tests, then open a PR titled `feat(#N): …` with `Closes #N`, filling in the PR template.
4. Never push to `main`, never commit secrets, never merge your own PR.
5. Blocked? Comment on the issue and add `blocked`.

Non-code work: use the **Work item** issue template.
