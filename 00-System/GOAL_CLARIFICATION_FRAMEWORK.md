# 🎯 GOAL CLARIFICATION FRAMEWORK
## Mandatory First Step. Every Project. No Exceptions.

**Problem:** We built 44 files for the wrong goal. This system prevents that forever.

---

## THE 5-QUESTION GATE

Before any work starts, answer these 5 questions. If you can't answer all 5, STOP and clarify.

### Q1: What is the PRIMARY goal? (One sentence)

```
"I want to __________________________________________."
```

**Rules:**
- One sentence. No more.
- Focus on OUTCOME, not activity.
- "Land a remote job" ✓ ("Apply to jobs" ✗ — that's an activity)
- "Generate $X/month" ✓ ("Build a brand" ✗ — that's a means, not an end)

**Our mistake:** We answered "Build a digital presence" instead of "Land a remote job ASAP"

---

### Q2: Who is the PRIMARY audience?

| Audience | They care about | Example content |
|----------|----------------|-----------------|
| Recruiters | Skills, experience, proof of work | LinkedIn, Resume, GitHub |
| Employers/Clients | Value you can deliver | Portfolio, case studies |
| Peers/Community | Your story, journey, lessons | X/Twitter, blog |
| Investors | Traction, metrics, vision | Pitch deck |

**Our mistake:** We wrote for peers (venture builder story) when we should have written for recruiters (focused developer).

---

### Q3: What does SUCCESS look like? (Measurable)

| Bad Success Criteria | Good Success Criteria |
|---------------------|---------------------|
| "Complete profile overhaul" | "LinkedIn updated → 20 recruiter DMs in 30 days" |
| "Build a content strategy" | "10 job applications/week → 1 interview by Week 4" |
| "Create a brand" | "$1,000/month revenue within 60 days" |

**Rule:** If you can't measure it on a calendar, it's not success criteria.

---

### Q4: What is the TIMELINE?

| Timeline | Strategy |
|----------|----------|
| ASAP (1-4 weeks) | Job search mode — focused, conversion-oriented |
| Short-term (1-3 months) | Build credibility while searching |
| Medium-term (3-12 months) | Personal brand building, audience growth |
| Long-term (12+ months) | Full ecosystem, multiple revenue streams |

**Our mistake:** We built a long-term personal brand when the timeline was ASAP job search.

---

### Q5: What is the SINGLE most important metric?

```
The one number that tells us if we're winning.
```

**Examples:**
- Job search: Number of recruiter conversations
- Freelance: Dollars invoiced
- Content: Newsletter subscribers
- Product: Monthly active users

**Our mistake:** We tracked "files created" instead of "recruiter conversations started."
