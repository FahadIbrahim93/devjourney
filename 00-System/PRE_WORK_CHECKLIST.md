# ✅ PRE-WORK CHECKLIST
## Run This Before Every Hermes Session

**Why:** We wasted 13 hours because we didn't check our assumptions.
**Fix:** This checklist. Every session. No exceptions.

---

## MANDATORY (5 min)

### ☐ Step 1: State the goal aloud

Write it down. One sentence.
_"This session I will..."_

### ☐ Step 2: Ask "Who is this FOR?"

- Recruiter?
- Client?
- Audience?
- Myself?

### ☐ Step 3: Ask "What does DONE look like?"

Not "files created" or "tasks completed."
**What CHANGE happens because of this work?**

### ☐ Step 4: Ask "What's the MOST important thing?"

If I only accomplish ONE thing this session, what should it be?

### ☐ Step 5: Set a 2-hour checkpoint

"After 2 hours, I will pause and ask: Is this still the right thing to be doing?"

---

## OPTIONAL (If Applicable)

### ☐ Research done?
Don't build without understanding the landscape.

### ☐ Audience analyzed?
Who exactly am I writing/building for?

### ☐ Existing assets reviewed?
What already exists that I can use or improve?

### ☐ Success criteria defined?
How will I know if this was worth the time?

---

## THE 2-HOUR CHECKPOINT

After 2 hours of work, stop and answer:

```
1. Am I still working on the MOST important thing?   ☐ Yes  ☐ No
2. Does this directly serve the primary goal?        ☐ Yes  ☐ No
3. If I stopped RIGHT NOW, was this time well spent? ☐ Yes  ☐ No
4. What should I do differently next 2 hours?        ────────
```

If "No" to any of the first 3 → STOP. Re-evaluate.

---

## THE 1-SENTENCE RULE

**Before creating any file or document, ask:**

> "If this is the ONLY thing I produce today, was it worth it?"

If the answer is no → don't create it.
