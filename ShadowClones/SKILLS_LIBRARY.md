## 🧠 HOW SKILLS WORK

Each clone has 6 specialized skills. When you say `/<skill-name>` in a chat with the active clone, it triggers that skill. Skills can also be auto-generated from patterns detected in #ShadowNetwork.

## 🔮 CRYPTO SAGE (6 Skills)

### 1. `chart_pattern_recognition`
**Purpose:** Identify classic patterns in BTC/ETH charts
**Trigger:** When chart image uploaded OR when asked "what's the chart saying?"
**Output:**
- Pattern identified (head & shoulders, triangle, wedge, etc.)
- Confidence (1-10)
- Implication (bullish/bearish/neutral)
- Action (entry/exit/wait)
- Risk level (low/med/high)

### 2. `onchain_flow_analysis`
**Purpose:** Track exchange reserves, whale movements, network activity
**Trigger:** Daily at market open + on-demand
**Output:**
- Exchange inflow/outflow (24h, 7d)
- Whale wallet changes (1K+ BTC)
- Network activity (hashrate, active addresses)
- Translation: bullish/bearish signal

### 3. `defi_yield_optimizer`
**Purpose:** Compare yield opportunities across DeFi protocols
**Trigger:** Weekly portfolio review OR "what's the best yield for X?"
**Output:**
- Top 5 yield opportunities (TVL, APY, risk)
- Risk-adjusted ranking
- Recommended allocation
- Impermanent loss considerations

### 4. `mining_profitability`
**Purpose:** Calculate ROI on mining hardware, electricity costs
**Trigger:** Monthly mining audit OR "is mining profitable?"
**Output:**
- Per-rig daily/monthly revenue
- Electricity costs
- Net profit/loss
- ROI timeline
- Recommendation (continue, upgrade, exit)

### 5. `sentiment_tracker`
**Purpose:** Track social sentiment, funding rates, fear/greed index
**Trigger:** Daily at market open + on-demand
**Output:**
- Fear & Greed Index (0-100)
- Funding rates (perpetuals)
- Social sentiment (Twitter, Reddit)
- Translation: market mood (fear, greed, neutral)

### 6. `ta_backtester`
**Purpose:** Backtest strategies on historical data
**Trigger:** New strategy proposed OR "backtest this"
**Output:**
- Strategy rules (entry, exit, position sizing)
- Historical performance (1Y, 3Y, 5Y)
- Win rate, max drawdown, Sharpe ratio
- Recommendation (viable, marginal, skip)

## 📚 SKILL FILE STRUCTURE

Each skill is stored in:
```
~/.hermes/skills/<skill-name>/
├── SKILL.md           # Skill definition
├── examples/          # Example invocations + outputs
├── tests/             # Test cases
└── assets/            # Reference materials (if applicable)
```

```

Or:
```

## 🧪 SKILL AUTO-GENERATION

When #ShadowNetwork detects a repeated pattern (5+ similar insights), it auto-generates a new skill:

Example:
- 5+ insights about "how to write Twitter threads that go viral"
- → Auto-creates `viral_thread_writer` skill
- → Saves to `~/.hermes/skills/viral_thread_writer/`
- → Available for all clones to invoke
