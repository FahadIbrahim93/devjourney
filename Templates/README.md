# Templates — Hope Theory

Reusable templates for all Hope Theory work.

| Template | Use When |
|----------|----------|
| `SESSION.md` | Start every work session |
| `SPRINT.md` | Plan a sprint (1-2 weeks) |
| `PROJECT_BRIEF.md` | Create a new project or deeply document one |
| `SESSION_WRAPUP.md` | End of session — what was done |

## How to Use

Copy the template, fill in the brackets, use it.

```bash
# Start a session
cp Templates/SESSION.md SESSION.md

# Plan a sprint
cp Templates/SPRINT.md SPRINT.md

# Create a project brief
cp Templates/PROJECT_BRIEF.md Projects/<name>/PROJECT_BRIEF.md
```
