# Hope Theory — Portfolio
## Deploy to GitHub Pages

This folder contains a single-file portfolio site ready for static hosting.

### Files
- `index.html` — Complete portfolio page (17KB, zero dependencies)

### Deploy Options

**Option A: GitHub Pages**
```bash
# From repo root
git subtree push --prefix=portfolio origin gh-pages
```
Then enable GitHub Pages in repo settings → source: `gh-pages` branch.

**Option B: Netlify Drop**
Go to https://app.netlify.com/drop and drag this `portfolio/` folder.

**Option C: Vercel**
```bash
cd portfolio && npx vercel --prod
```
