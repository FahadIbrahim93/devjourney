---

### 4. REVISIONS

**Included Revisions:** [2-3 rounds] of revisions per milestone.

**Additional Revisions:** Billed at $____/hour.

**Revision Scope:** Minor changes to existing functionality. New features or major changes are considered additional work.

---

### 5. INTELLECTUAL PROPERTY

**Upon final payment**, all rights to the delivered code and assets transfer to the Client.

**Freelancer retains the right to:**
- Use the project in portfolio and case studies
- Reference the work in proposals and marketing materials

**Third-party assets** (libraries, frameworks, stock images) remain under their respective licenses.

---

### 6. CONFIDENTIALITY

Both parties agree to keep confidential any proprietary information shared during the project.

---

### 7. TERMINATION

**By Client:** Client may terminate with 7 days written notice. Client pays for all work completed to date.

**By Freelancer:** Freelancer may terminate with 7 days written notice if:
- Client fails to provide necessary materials/feedback within 14 days
- Payment is overdue by 14+ days
- Scope changes exceed 30% of original agreement

---

### 8. LIABILITY

Freelancer's liability is limited to the total project fee. Freelancer is not liable for:
- Indirect or consequential damages
- Loss of profits or data
- Issues caused by third-party services

---

### 9. WARRANTY

Freelancer provides a **30-day bug fix warranty** after final delivery, covering:
- Bugs in code written by Freelancer
- Issues preventing core functionality

Warranty does NOT cover:
- Issues caused by Client modifications
- Browser/Device compatibility issues not specified
- Third-party service changes

---

### 10. DISPUTE RESOLUTION

Both parties agree to attempt resolution through good-faith negotiation before pursuing legal action.

# QUICK-START CHECKLIST FOR USING THESE CONTRACTS

## Before Sending:
- [ ] Choose the right contract type for the project
- [ ] Fill in all [BRACKETS] with specific details
- [ ] Define clear scope (what's IN, what's OUT)
- [ ] Set realistic timeline with buffer
- [ ] Specify payment schedule with percentages
- [ ] Include warranty terms (30 days standard)
- [ ] Add late payment fee clause

## Sending to Client:
- [ ] Use DocuSign or HelloSign for e-signatures (or PDF + email)
- [ ] CC yourself on the sent contract
- [ ] Save signed copy to client folder
- [ ] Set up payment reminders for each milestone

## After Signing:
- [ ] Send welcome email with onboarding questionnaire
- [ ] Set up shared communication channel (Slack, Discord, etc.)
- [ ] Create project folder structure
- [ ] Schedule kickoff call
- [ ] Add client to tracking dashboard

## Legal Notes:
- These are template contracts. For projects over $5,000, consult with a lawyer.
- Laws vary by jurisdiction — ensure compliance with local regulations.
- Consider using And.co, Bonsai, or HoneyBook for automated contract management.
