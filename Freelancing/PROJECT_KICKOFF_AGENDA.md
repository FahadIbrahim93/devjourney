## PRE-MEETING PREPARATION
- [ ] Send calendar invite with agenda attached (3+ days in advance)
- [ ] Request any needed pre-work from client (access, documentation, etc.)
- [ ] Prepare presentation slides or visual aids
- [ ] Test all technology (screen sharing, audio, video)
- [ ] Have contract, proposal, and timeline documents ready for reference
- [ ] Prepare list of questions for client
- [ ] Set up recording if client consents (for reference only)

## AGENDA

### 1. Welcome & Introductions (10 minutes)
- [ ] Warm welcome and personal introductions
- [ ] Brief icebreaker if team hasn't worked together before
- [ ] Review meeting objectives and agenda
- [ ] Establish meeting norms (phones on mute, respectful dialogue, etc.)

### 2. Project Vision & Goals (15 minutes)
- [ ] Client shares business context and motivation for project
- [ ] Review project objectives from proposal/contract
- [ ] Define clear success metrics and how we'll measure them
- [ ] Discuss what "done" looks like for this project
- [ ] Align on priorities if multiple objectives exist

### 3. Scope Review & Clarification (15 minutes)
- [ ] Walkthrough of agreed-upon deliverables
- [ ] Review what's explicitly IN scope
- [ ] Review what's explicitly OUT of scope
- [ ] Identify any gray areas needing clarification
- [ ] Confirm acceptance criteria for each deliverable
- [ ] Discuss potential scope change process

### 4. Project Approach & Methodology (15 minutes)
- [ ] Present development lifecycle approach (Agile/Scrum/Waterfall/etc.)
- [ ] Review technology stack and architectural decisions
- [ ] Explain quality assurance and testing approach
- [ ] Discuss AI/ML specific considerations if applicable
- [ ] Review tools we'll be using (project tracking, communication, etc.)
- [ ] Define Definition of Done (DoD) for work items

### 5. Timeline & Milestones (15 minutes)
- [ ] Review high-level project timeline
- [ ] Walkthrough of key milestones and deliverable dates
- [ ] Review payment schedule tied to milestones
- [ ] Identify dependencies or critical path items
- [ ] Discuss buffer time for unexpected challenges
- [ ] Confirm working hours and availability expectations

### 6. Communication & Collaboration (10 minutes)
- [ ] Establish primary communication channels (email, Slack, Teams, etc.)
- [ ] Set meeting cadence (weekly syncs, demos, etc.)
- [ ] Define response time expectations (e.g., "within 2 business hours")
- [ ] Review reporting format and frequency (status reports, etc.)
- [ ] Establish escalation process for blockers or issues
- [ ] Review demo and feedback review process

### 7. Roles & Responsibilities (10 minutes)
- [ ] Clarify client-side responsibilities (feedback, approvals, access)
- [ ] Review freelancer/team responsibilities
- [ ] Identify primary points of contact on both sides
- [ ] Define decision-making authority and process
- [ ] Review stakeholder engagement plan
- [ ] Clarify who needs to attend which meetings

### 8. Risks, Assumptions & Constraints (10 minutes)
- [ ] Identify known project risks and mitigation strategies
- [ ] Review key assumptions made in planning
- [ ] Discuss any known constraints (budget, timeline, resources)
- [ ] Establish risk review process (when/how we'll revisit risks)
- [ ] Discuss contingency planning approach

### 9. Immediate Next Steps & Action Items (10 minutes)
- [ ] Review and confirm all action items from meeting
- [ ] Assign owners and due dates for each action item
- [ ] Schedule next meeting(s)
- [ ] Confirm access/permissions needed to begin work
- [ ] Establish when initial work will begin
- [ ] Share where project documentation will be stored

### 10. Q&A & Closing (5 minutes)
- [ ] Open floor for any remaining questions or concerns
- [ ] Reiterate enthusiasm and commitment to project success
- [ ] Confirm next meeting date/time
- [ ] Thank everyone for their time and participation

## POST-MEETING FOLLOW-UP

### Within 24 Hours:
- [ ] Send meeting notes with decisions, action items, and owners
- [ ] Share project timeline/milestones in accessible format
- [ ] Upload any presentation materials or documents shared
- [ ] Add action items to project tracking system
- [ ] Schedule recurring meetings as discussed
- [ ] Begin work on any immediate action items

### Within 3 Days:
- [ ] Follow up on any outstanding access or permission requests
- [ ] Send welcome package or onboarding materials if applicable
- [ ] Verify all action items are progressing as planned
- [ ] Address any questions or concerns that arose post-meeting

## MEETING EFFECTIVENESS CHECKLIST

After the meeting, evaluate:
- [ ] Did we start and end on time?
- [ ] Were all key stakeholders present or represented?
- [ ] Did we achieve our meeting objectives?
- [ ] Was there clear agreement on goals, scope, and approach?
- [ ] Are action items clearly assigned with owners and due dates?
- [ ] Did we establish effective communication rhythms?
- [ ] Did we identify and begin addressing key risks?
- [ ] Did we leave the client feeling confident and excited?

## VIRTUAL MEETING TIPS

If meeting remotely:
- [ ] Test all technology 15 minutes before start
- [ ] Use video when possible for better engagement
- [ ] Share screen to review documents together
- [ ] Use virtual whiteboard or annotation tools for collaboration
- [ ] Record meeting (with permission) for those who couldn't attend
- [ ] Use chat function for questions and resource sharing
- [ ] Send materials in advance for those with bandwidth issues
- [ ] Build in extra time for technical difficulties
- [ ] Use breakout rooms if needing small group discussions
- [ ] Check in regularly for understanding and engagement

## IN-PERSON MEETING TIPS

If meeting in person:
- [ ] Choose neutral, professional location
- [ ] Ensure adequate seating and visibility for all
- [ ] Provide necessary adapters/cables for presentations
- [ ] Have water and light refreshments available
- [ ] Arrange furniture to facilitate discussion
- [ ] Have whiteboard or flip chart available
- [ ] Provide printed copies of key documents
- [ ] Take photos of whiteboard content for sharing
- [ ] Follow up with digital copies of any physical artifacts
