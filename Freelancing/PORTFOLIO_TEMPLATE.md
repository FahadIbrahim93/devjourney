## PORTFOLIO BEST PRACTICES

### Selection Criteria
1. **Recency:** Prefer projects from last 12-18 months
2. **Relevance:** Match to target client industries/needs
3. **Impact:** Showcase measurable results
4. **Variety:** Display range of skills and technologies
5. **Quality:** Only include your best work

### Presentation Tips
- Keep case studies concise (300-500 words)
- Lead with results, not process
- Use client quotes when available
- Show, don't just tell (visuals > descriptions)
- Optimize for scanning (headers, bullet points, bold text)
- Include metrics whenever possible (% improvement, $ saved, time reduced)

### Platform-Specific Optimization
**Website Portfolio:**
- Dedicated page per case study
- Filterable by industry/technology/type
- Clear contact CTA on every page

**PDF Portfolio:**
- 1-2 pages per project max
- Consistent branding throughout
- Include table of contents for multi-project PDFs

**LinkedIn:**
- Featured section for top 3-5 projects
- Articles summarizing key learnings
- Regular posts highlighting different projects

**GitHub:**
- Clean, well-documented repositories
- Live demos linked in README
- Clear installation/instructions

### Updating Schedule
- **Monthly:** Add new completed projects
- **Quarterly:** Remove outdated projects (>2 years unless exceptional)
- **Bi-annually:** Refresh metrics and client testimonials
- **Annually:** Complete portfolio redesign/refresh
