# CLIENT ONBOARDING CHECKLIST

Use this checklist to ensure a smooth start to every client relationship.

## PRE-KICKOFF PREPARATION

### Initial Contact & Qualification
- [ ] Respond to inquiry within 2 business hours
- [ ] Schedule discovery call (30-45 minutes)
- [ ] Send calendar invite with video conferencing link
- [ ] Research client/company before call
- [ ] Prepare discovery questions tailored to their industry

### Discovery Call
- [ ] Conduct discovery call using structured agenda
- [ ] Take detailed notes on goals, constraints, budget, timeline
- [ ] Identify decision-makers and stakeholders
- [ ] Discuss communication preferences and frequency
- [ ] Determine if project is a good fit (skills, budget, timeline)
- [ ] Provide preliminary insights or observations

### Proposal Preparation
- [ ] Analyze discovery notes and requirements
- [ ] Define clear scope and deliverables
- [ ] Estimate effort and timeline realistically
- [ ] Determine pricing strategy (hourly vs project-based)
- [ ] Identify potential risks and mitigation strategies
- [ ] Prepare detailed proposal using template
- [ ] Include relevant case studies or portfolio examples
- [ ] Review proposal for clarity and completeness

### Proposal Delivery
- [ ] Send proposal within promised timeframe
- [ ] Schedule follow-up call to review proposal (don't just send and wait)
- [ ] Be prepared to answer questions and make adjustments
- [ ] Negotiate in good faith while maintaining boundaries
- [ ] Address any scope or timeline concerns

## CONTRACT & LEGAL

### Agreement Finalization
- [ ] Incorporate agreed-upon changes from proposal review
- [ ] Generate contract using template
- [ ] Include any specific terms discussed (IP, confidentiality, etc.)
- [ ] Add AI-specific addendum if applicable
- [ ] Send contract for review and signature
- [ ] Follow up if not returned within 3 business days
- [ ] Store signed contract in client's folder

### Administrative Setup
- [ ] Create client folder in filing system
- [ ] Set up project tracking (Trello/Asana/notion/etc.)
- [ ] Create time tracking entry/project code
- [ ] Set up invoicing template with client details
- [ ] Add client to CRM or tracking spreadsheet
- [ ] Configure communication channels (email, Slack, etc.)
- [ ] Set up shared file storage (Google Drive, Dropbox, etc.)
- [ ] Establish version control repository if needed

## KICKOFF MEETING

### Preparation
- [ ] Schedule kickoff meeting (60-90 minutes)
- [ ] Invite all relevant stakeholders
- [ ] Prepare presentation deck (agenda, goals, process, timeline)
- [ ] Prepare list of needed access/permissions
- [ ] Prepare questions for client about preferences/constraints
- [ ] Test all technology (video conferencing, sharing, etc.)

### Meeting Execution
- [ ] Start with introductions and rapport building
- [ ] Review project goals and success metrics
- [ ] Present detailed project plan and timeline
- [ ] Review communication protocols and frequency
- [ ] Establish decision-making process
- [ ] Review change request procedure
- [ ] Discuss tools and platforms to be used
- [ ] Identify potential blockers or dependencies
- [ ] Establish meeting cadence (weekly syncs, demos, etc.)
- [ ] Confirm next steps and action items

### Post-Kickoff
- [ ] Send meeting notes and action items within 24 hours
- [ ] Share project plan/timeline in accessible format
- [ ] Set up recurring meetings in calendar
- [ ] Begin initial work tasks as planned
- [ ] Send welcome package or onboarding materials if applicable

## FIRST TWO WEEKS

### Communication & Trust Building
- [ ] Send daily brief progress updates (even if just "working on X")
- [ ] Schedule first demo/review at end of week 1
- [ ] Be proactive about asking clarifying questions
- [ ] Over-communicate rather than under-communicate
- [ ] Show early wins or progress to build confidence

### Process Establishment
- [ ] Establish definition of "done" for deliverables
- [ ] Set up quality assurance process (testing, reviews)
- [ ] Confirm feedback collection and implementation process
- [ ] Establish escalation path for issues or blockers
- [ ] Review and adjust communication frequency if needed
- [ ] Gather feedback on process and make adjustments

### Documentation
- [ ] Begin maintaining project documentation/living docs
- [ ] Record key decisions and rationale
- [ ] Update project timeline as needed based on learnings
- [ ] Document any scope changes or assumptions
- [ ] Keep time tracking accurate and up-to-date

## ONBOARDING COMPLETION CRITERIA

Consider onboarding complete when:
- [ ] Contract signed and administratively set up
- [ ] Kickoff meeting held and notes distributed
- [ ] Communication channels and rhythms established
- [ ] Initial work begun and progress demonstrated
- [ ] Client expresses confidence in process and capabilities
- [ ] Any initial concerns or questions addressed
- [ ] Project documentation started and accessible

## CLIENT-SPECIFIC NOTES

For AI/ML Projects:
- [ ] Discuss data requirements, ownership, and privacy considerations
- [ ] Clarify expectations around model performance and accuracy
- [ ] Explain limitations and potential biases of AI approaches
- [ ] Discuss model maintenance and updating plans
- [ ] Address intellectual property considerations for models/data

For Long-Term/Ongoing Engagements:
- [ ] Establish retainer or recurring billing structure if applicable
- [ ] Set up regular strategic reviews (monthly/quarterly)
- [ ] Plan for knowledge transfer and documentation
- [ ] Discuss scaling or evolving scope over time

For Fixed-Price Projects:
- [ ] Clearly define scope boundaries and change control process
- [ ] Establish milestones tied to payments
- [ ] Build in buffer for unexpected complexity
- [ ] Define what constitutes a change vs. clarification

---

## RED FLAGS TO WATCH FOR

During onboarding, be alert for:
- Unwillingness to sign basic contract or discuss terms
- Vague or constantly changing requirements
- Unrealistic timelines or budgets
- Poor communication or responsiveness during sales process
- Lack of clear decision-maker or approval process
- Requests for significant unpaid work ("just do a quick sample")
- History of problematic freelancer relationships (if revealed)
- Pressure to start immediately without proper planning

If red flags appear, consider:
- Having an honest conversation about concerns
- Adjusting terms or scope to mitigate risks
- Walking away if fundamental mismatches exist
- Trusting your instincts about client fit
